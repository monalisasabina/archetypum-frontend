# 🏛️ Archetypum-Africa Website

This repository contains the source code for the official website of [Archetypum-Africa].  
It is built with **React.js (Vite)** to showcase our projects, services, and contact information in a modern and professional design.

---

## 🚀 Getting Started

Follow these steps to set up and run the project locally on your computer.

### 1. Fork and clone the Repository
Click the **Fork** button at the top-right of this repository page to create your own copy under your GitHub account.

Then open your terminal and clone. When successful, move into the project folder

### 2. Install dependencies
Ensure Node.js and npm are installed
   
   ```bash
   node -v

   
   npm -v
   ```
Then install required packages 
   
   ```bash
   npm install
   ```


### 4. Run the Server

To start the server
   
   ```bash
   npm run dev

   ```

By default, you will use the link below to open the website locally:

    http://localhost:5173/
